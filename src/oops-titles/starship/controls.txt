# The start-up controls card (common/controls_card.h): the port's own defaults
# (upstream/src/port/Engine.cpp:142-163).
Left stick = Fly
Cross = Fire (A)
Square = Bomb (B)
Triangle / R2 = Boost
Circle / L2 = Brake
R1 / L1 = Tilt right / left
Right stick up = Camera view
Right stick right = Answer the radio
Options = Pause (Start)
Create = Port menu
