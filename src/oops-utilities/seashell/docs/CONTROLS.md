# SeaShell - controls

Input map. See [FEATURES](FEATURES.md) for what each screen does.

| input | action |
|---|---|
| **Home Button** (`bit 16`) | Toggle Control Centre overlay (open / close) |
| **L1 / R1** | Switch between category modes or tabs |
| **D-pad / Sticks** | Navigate; press fires immediately, then repeats after the initial hold delay |
| **Cross / Enter** | Select / activate the current item |
| **Circle / Back** | Return to the previous screen or cancel a dialog |
| **Triangle** | Open Universal Search |
| **Options / Menu** | Open the Title Options context menu |
| **Square** | Open the Game Library |
